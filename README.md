# Embedded Obstacle Game (2018)

An interactive embedded C/C++ project where players navigate through randomly generated obstacles using a joystick, rendered on a TFT ILI9163C display module.

### Key Features
* **Joystick Control:** Responsive input for real-time player navigation.
* **TFT ILI9163C Display:** Visual rendering on a 128x128 color display module.
* **Procedural Obstacles:** Dynamic, randomly generated obstacles to challenge the player.
* **Legacy Codebase:** Archived project repository from 2018.
